\section{Conclusion}
\label{sec:conclusion}

\textsc{FinOPD} treats financial self-evolution as a scheduling problem: one 9B policy acts on point-in-time structured evidence, the frozen 27B teacher becomes available only after outcomes mature, and policy, router, factor library, and episodic memory change on explicitly different clocks. One cost-aware utility links deterministic coalition replay, recorded router actions, and memory admission, while full-vocabulary token and reference-level guards constrain transfer. The artifact now enforces that contract through fail-fast data isolation, real price-path utility, content-addressed factors, availability-filtered retrieval, synchronized portfolio evaluation, and dependence-aware uncertainty. Component audits validate the executable path, but the locked Qwen3.5 financial matrix is incomplete; we therefore make no return-superiority claim. Completing that matrix and a true forward window is necessary before claiming statistical, causal, or live robustness.
