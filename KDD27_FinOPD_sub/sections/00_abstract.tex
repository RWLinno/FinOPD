\begin{abstract}
Financial agents can reason over rich evidence, but their policies rarely learn from the delayed portfolio outcomes they create. Doing so is difficult because trajectories are endogenous to the current policy, terminal utility is shared across components, and hindsight must never enter deployment. We present \textsc{FinOPD}, a temporally staged framework that turns outcome-matured trajectories into dense supervision for one deployable token policy. A Qwen3.5-9B student acts from point-in-time structured evidence; only after horizon closure does a frozen Qwen3.5-27B teacher observe five outcome scalars. A single cost-aware utility drives deterministic coalition replay, recorded-action factor-router updates, and availability-filtered episodic-memory admission, while full-vocabulary JSD and round-start reference KL stabilize transfer. The system couples this update with a content-addressed binary artifact of 157 executable factors without exposing the source manifest. Implementation audits execute every factor with finite outputs, recover the ordered top-15 router action, enforce time-safe retrieval, and exercise local 9B/27B generation and one-step distillation. The reproduction artifact also provides a fail-closed evaluation harness for synchronized portfolio PnL, three seeds, 20-day block bootstrap, and Holm correction; it reports missing arms instead of substituting proxy results. Financial comparisons are intentionally withheld until all locked Qwen3.5 checkpoints and daily-return manifests exist.
\end{abstract}
