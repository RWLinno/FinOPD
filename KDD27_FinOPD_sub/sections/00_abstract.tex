\begin{abstract}
Financial agents can reason over rich evidence, but their policies rarely learn from the delayed portfolio outcomes they create. Doing so is difficult because trajectories are endogenous to the current policy, terminal utility is shared across agents, and hindsight must never enter deployment. We present \textsc{FinOPD}, a temporally staged framework that turns outcome-matured trajectories into dense policy supervision. A deployable Qwen3.5-9B student acts from point-in-time evidence; only after horizon closure does a frozen Qwen3.5-27B teacher observe a compact hindsight summary. A single cost-aware utility drives deterministic coalition credit, straight-through factor routing, and time-safe memory admission, while token-level JSD and a round-start reference KL stabilize transfer. The system couples this parametric update with a content-addressed library of 157 executable factors and regime-aware abstention. In a retrospective point-in-time study on four U.S. large-cap equities from January 2025 to May 2026, \textsc{FinOPD} ranks first among 13 methods by macro-averaged per-asset return, Sharpe, and Calmar (60.9\%, 1.41, and 3.30). Temporal slices and intervention diagnostics expose where the advantage holds and where it fails; synchronized-PnL and dependence-aware evaluation code prevents these macro-averages from being mistaken for portfolio statistics.
