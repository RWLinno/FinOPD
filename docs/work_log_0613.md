### 1. 实现缺陷诊断(为什么之前表现差)

| OPD LoRA 微调 VLM | vLLM 只挂基座 32B,未挂 LoRA | 改用 7B + opd_lora(自训练权重) |
| 160+ 进化因子 | 只用 top 20 | 扩到全部 142(IR>=0.5) |
| 满仓决策 | 仓位仅 5-36%(收益稀释 3-13x) | 满仓趋势骑乘(0.6-1.0) |
| Factor Router | 权重缺失,软跳过 | (待补) |
| Belief Store | 完全未接入 | (待补) |
| 多模态文本 | EventAnalyst 是 stub | (待补) |

### 2. VLM 性能优化
- 32B 模型每天推理 28s → 7B+opd_lora 每天 6.4s(快 4.4x)
- 新增 VLM 内容哈希缓存(`src/finvl/visual/vlm_client.py`),重跑秒级
- 清空了空转 4 天的 32B vLLM(占满 4×A800),换 7B(2 卡 TP=2)

### 3. 仓位修复(收益核心)
- 根因:`_adjust_position_size` 把仓位压到 5-36%,GOOGL 涨 65% 只赚 8.6%
- 修复:满仓趋势骑乘 + 下跌平仓(long-only carry)
- 效果(GOOGL 因子模式):CR 8.6%→75.4%,SR 1.70→2.44

## 诚实结论
- 满仓修复后,GOOGL/JNJ/GS 收益大幅提升(SR 2.0+,CR 30-77%),收益问题已基本解决。
- 但满仓后 MDD 升到 ~10%(不再是之前的 2-3%),FinOPD **不再单靠极低 MDD 取胜**。
- 严格同口径下,FinOPD 在单一资产上**未能全 4 指标碾压所有 baseline**——动量类时序模型(iTransformer/TimesNet)在趋势股上 SR 天然很高。
- 真实可展示的优势:强势资产上 SR 2.0+(有竞争力)+ 完整多模态自进化方法论。
