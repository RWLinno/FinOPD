\section{Experiments}
\label{sec:experiments}

\subsection{Setup}

\paragraph{Datasets.}
We evaluate on two markets: (1)~\textbf{CSI300} (Chinese A-shares, daily, 2008--2020), widely used in quantitative finance research~\cite{rdagent2025}; and (2)~\textbf{S\&P500} (US equities, daily, 2000--2023), providing international comparison.

\paragraph{Temporal splits.}
We use strict walk-forward evaluation with no data leakage. For CSI300: train 2008--2014, validation 2015--2016, test 2017--2020. For S\&P500: train 2000--2015, validation 2016--2018, test 2019--2023. All features and chart renderings use only data up to and including the decision date (point-in-time alignment).

\paragraph{Baselines.}
We compare against: (1)~Buy-and-Hold; (2)~PatchTST~\cite{nie2023patchtst} numerical encoder; (3)~Single-Agent VLM (chart image $\rightarrow$ single prompt $\rightarrow$ decision); (4)~FinCon-style multi-agent LLM (text only)~\cite{fincon2024}; (5)~Traditional quantitative strategies (MA crossover, momentum).

\paragraph{Metrics.}
Annualized return, Sharpe ratio (with and without 15bps round-trip transaction costs), maximum drawdown, Calmar ratio, information coefficient (IC), rank IC, and directional accuracy. All metrics computed on the test period.
